# Сайт Боруссии Санкт-Петербург

## Как устроен сайт

- `index.html`: страница, которую видят болельщики. Ничего в нём менять не нужно.
- `data/site.json`: все данные сайта (состав, матчи, статистика, фото, контакты).
- `images/uploads/`: загруженные фото.
- `admin/`: панель управления. Открывается по адресу `ваш-сайт/admin/`.

## Как пользоваться панелью

1. Откройте `ваш-сайт/admin/` и войдите под своим аккаунтом GitHub.
2. Слева выберите раздел: состав, расписание, результаты, статистика, фотогалерея, контакты.
3. Чтобы добавить фото в галерею, нажмите **New Фотогалерея** (или «Добавить»), загрузите файл, добавьте подпись и при желании ссылку на видео.
4. Чтобы обновить статистику, откройте раздел «Статистика» и поменяйте цифры.
5. Нажмите **Publish** (Опубликовать). Через 1–2 минуты изменения появятся на сайте.

**Видео.** Загружайте видео на YouTube или VK Видео, а в панели вставляйте ссылку. Сами видеофайлы на сайт не загружайте: они тяжёлые.

**Фото.** Лучше загружать фото в сжатом виде, до 1 МБ. Так сайт работает быстрее.

## Одноразовая настройка (делает администратор сайта)

1. Создать аккаунт на github.com и новый публичный репозиторий, например `borussia-spb-site`.
2. Загрузить в репозиторий все файлы из этой папки.
3. В `admin/config.yml` заменить `YOUR_GITHUB_LOGIN/borussia-spb-site` на свой логин и название репозитория.
4. Включить сайт: в настройках репозитория раздел **Pages**, источник «Deploy from a branch», ветка `main`, папка `/ (root)`.
5. Настроить вход в панель. Это нужно один раз: в инструкциях Decap CMS описано два способа — через Netlify Identity или через OAuth-приложение GitHub. Самый простой способ — хостинг на Netlify с подключением Identity и Git Gateway.

## Предупреждения

- Не удаляйте файл `data/site.json` и не переименовывайте папки `data` и `admin`.
- Не редактируйте `data/site.json` вручную, если уже пользуетесь панелью: это может сломать формат. Если всё же правите вручную, сохраняйте кавычки и запятые.
- Локально (двойной клик по `index.html`) сайт не покажет данные. Откройте его через хостинг или запустите `python3 -m http.server` в этой папке и откройте `http://localhost:8000`.
